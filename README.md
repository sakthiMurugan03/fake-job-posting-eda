# Fake Job Posting Detection (EDA Dashboard)

## 📌 Overview

This project performs Exploratory Data Analysis (EDA) on job postings to identify patterns in fraudulent job listings.
An interactive Streamlit dashboard is built to visualize fake vs real jobs and detect suspicious postings.

## 🎯 Use Case

Fake job listings mislead candidates and may collect personal data.
This project analyzes job postings to identify characteristics of fraudulent listings.

## ⚙️ Features

* Interactive Streamlit dashboard
* Fake vs Real job distribution
* Description length analysis
* Company logo vs fraud analysis
* Remote job fraud detection
* Suspicious job scoring
* Dataset filtering and search

## 🛠️ Tech Stack

* Python
* Pandas
* Seaborn
* Matplotlib
* Streamlit

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📊 Expected Outcome

* Fake jobs usually have short descriptions
* Fake jobs often lack company logo
* Remote jobs show higher fraud probability
* Suspicious jobs are highlighted

## 📁 Dataset

Fake Job Postings Dataset (Kaggle)
